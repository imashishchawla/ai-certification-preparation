💡 The One Big Idea

If you remember nothing else, remember this. Almost every correct answer in these 170 questions comes from ONE philosophy.

🧒 Explained for a kid
Picture a school. There's a teacher (the coordinator) and lots of students (subagents). Each student sits in a separate room. They cannot hear each other and cannot hear the teacher unless she writes a note and hands it to them.
🏆 The Golden Rule
"Information never travels by magic. Somebody must hand it over on purpose."
Humans assume robots share a brain. The exam says: they don't. Every correct answer makes data move on purpose — written down, structured, handed across.

Why this one idea answers ~40 questions

🍳 The 5-Step Answer Recipe

Tap each step to open it. Do these five in order and you'll never panic again.

  1. Step 1 — Who is asking?

    Read the scenario header. It tells you the world: Multi-Agent Research, Customer Support, CI/CD, Data Extraction, or Claude Code Workflow. Each world has its own favorite answer.
    tap to open

  2. Step 2 — What is broken?

    Every scenario has a wound: "the agent retries forever," "the slot gets stolen," "the report has no citations," "context is full." Circle the wound. The answer always heals that exact wound — nothing more.
    tap to open

  3. Step 3 — Throw out the 3 fake friends

    Three wrong answers are always the same three fakes: (1) "just tell the model in the prompt", (2) "hey, ask the human", (3) "let's build a whole new robot / queue / classifier." Cross them out instantly. They sound smart but they don't fix the wound.
    tap to open

  4. Step 4 — Pick the "make-it-impossible" answer

    The winner usually removes the possibility of the mistake — not just asks nicely. Combine two calls into one (atomic). Add a flag the computer reads (structured error). Restrict the tools (allowedTools). Enforce with a hook. Make it impossible, don't make it polite.
    tap to open

  5. Step 5 — Sanity check with "fewer turns?"

    Good answers usually save time, tokens, or confusion. Bad answers add extra steps, extra robots, or extra round-trips. Ask: "does this make the system simpler and surer?" If yes — you picked right.
    tap to open
🔮 Teacher's Secret
The exam never rewards "trying harder with words." It always rewards changing the machine. If an answer mentions editing the prompt as the main fix, it's bait. 90% of the time.

📌 Scenario: The synthesis agent says "I can't find any research."

Options: A) give it tools to fetch other agents' histories · B) coordinator didn't include the outputs in the prompt · C) agents need a shared API connection · D) context window too small.

  1. Who is asking?

    🔬 Multi-Agent Research. So the Golden Rule is ON.
    tap

  2. What is the wound?

    The synthesis agent has zero research. Not a little — none.
    tap

  3. Kill the fakes

    A = "let a robot go grab stuff by itself" (magic). C = "shared API connection" (magic). D = "too small" → would give partial data, not none.
    tap

  4. Winner

    ✅ B — the coordinator forgot to hand over the notes. Classic Golden Rule.
    tap

📌 Scenario: Two tools — check slots, then book. 15% of bookings fail because someone else took the slot.

Options: A) better error message · B) tell the agent to retry in the prompt · C) add a temporary "hold" tool · D) combine into one find-and-book tool.

  1. Who is asking?

    Tool design world. The wound = a race: between "check" and "book" the world changes.
    tap

  2. What actually fixes a race?

    You can't fix a race with nicer words or after-the-fact apologies. You must do both things at the same instant.
    tap

  3. Kill the fakes

    A = apologise later. B = same race, just with hope. C = adds a lock that can time out and gets complicated.
    tap

  4. Winner

    ✅ D — combine into ONE atomic tool. Check + book = one motion. Race impossible.
    tap

📌 Scenario: A customer is frustrated but the refund is easy and available NOW.

Options: A) just do the refund silently · B) escalate immediately · C) acknowledge, say it's fixable now, offer to fix OR escalate · D) ask lots of questions first.

  1. Who is asking?

    🎧 Customer Support. Goal written in scenario: 80% first-contact resolution — fix it on the FIRST try.
    tap

  2. The two goals fight

    Be kind (customer is angry) AND be efficient (fixable now). The winner honors both.
    tap

  3. Kill the fakes

    A ignores feelings. B ignores the easy fix. D slows everything down.
    tap

  4. Winner

    ✅ C — feel + fix + give choice. Respects the human and the goal at once.
    tap

🪤 Trap Hall of Fame

The 12 costumes worn by the wrong answers. Spot the costume, skip the trap.

1 · "Let's parallelize!"

Spawning many subagents with no plan floods tokens and fragments answers. Real fix: find entry points, then trace.

2 · "Ask the user / engineer"

The scenario says the human is NEW or already explained. Punting to them = the agent failed its job.

3 · "Read EVERYTHING"

Brute force blows the context window instantly. Real fix: targeted search, incremental read.

4 · "Subagents share context"

FALSE. Clean rooms. Coordinator must hand data over explicitly.

5 · "PostToolUse prevents mistakes"

Post means AFTER. It can't stop what already happened. Fix the prompt/tools instead.

6 · "Hardcode the decision tree"

Brittle — breaks on weird inputs. Real fix: let the model reason dynamically.

7 · "Fetch all pages"

Slow + floods context. Real fix: first page + count + a cursor to fetch more only if needed.

8 · "Return empty on error"

Empty looks like "nothing exists" → the agent invents false answers. Retry transient errors inside the tool instead.

9 · "Words will fix math"

Models are shaky at numeric thresholds. Real fix: compute the boolean on the backend.

10 · "Resume the whole old chat"

Stale tool results poison the new question. Real fix: fresh session + clean summary + fresh calls.

11 · "Sliding window keeps key facts"

No — it drops IDs, allergies, exact numbers. Real fix: structured state + progressive summary.

12 · "97% overall is good enough"

Overall hides a terrible segment. Real fix: check accuracy per document type & per field.

Secrets to memorize
  • If it says "put it in the prompt" as the main fix → suspicious.
  • If it says "make it impossible" (combine, restrict, schema, hook) → likely correct.
  • If it asks the human for something they don't have → wrong.
  • If it adds a new agent / queue / classifier for a simple problem → wrong.
  • If it moves data on purpose → right.
  • If it saves turns, tokens, or confusion → right.
