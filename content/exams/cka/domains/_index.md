Use these domain guides to navigate your CKA preparation. Each overview explains the core administration competencies tested, essential `kubectl` commands, and links to domain practice.

1. [D1: Troubleshooting (30%)](d1/) — cluster and node diagnostics, control plane failure recovery, application log triage, and networking fixes.
2. [D2: Cluster Architecture, Installation & Configuration (25%)](d2/) — RBAC, cluster deployment via `kubeadm`, control plane upgrades, `etcd` backup and restore, and HA topologies.
3. [D3: Services & Networking (20%)](d3/) — pod-to-pod networking, Service types, Ingress controllers, Gateway API, and NetworkPolicies.
4. [D4: Workloads & Scheduling (15%)](d4/) — Deployments, rollouts and rollbacks, ConfigMaps/Secrets, DaemonSets, affinity, taints, and tolerations.
5. [D5: Storage (10%)](d5/) — StorageClasses, dynamic provisioning, access modes, Persistent Volumes (PVs), and Persistent Volume Claims (PVCs).
