Domain 1 accounts for **8% (approx. 5 questions)** of the TA-004 exam. It validates your understanding of foundational Infrastructure as Code concepts, the differences between declarative vs. imperative approaches, and how Terraform provides a consistent workflow across multi-cloud and hybrid environments.

## What to practice

- Explain what Infrastructure as Code (IaC) is and contrast declarative definitions with imperative automation scripts.
- Identify the advantages of IaC patterns: repeatability, auditability, self-documentation, version control, and automated change tracking.
- Explain how Terraform manages multi-cloud, hybrid cloud, and service-agnostic workflows using provider abstractions without coupling configurations to a single platform.
