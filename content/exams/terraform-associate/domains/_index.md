7. [D7: Maintain Infrastructure with Terraform (6%)](d7/) — importing existing resources (`terraform import`), state inspection CLI commands, and log levels (`TF_LOG`).
8. [D8: HCP Terraform (8%)](d8/) — workspaces, project organization, run triggers, team access governance, and cloud integrations.
