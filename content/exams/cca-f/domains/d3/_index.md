Claude Code behavior depends on project instructions, available tools, permissions, and the way work is checked. This domain covers how to keep guidance relevant to a repository, when to use hooks for repeatable checks, and how to plan and review changes without losing important context.

## What to practice

- Place guidance at the level where it applies.
- Use hooks for checks that need consistent enforcement.
- Choose a workflow that gives the agent enough context and a clear verification step.
