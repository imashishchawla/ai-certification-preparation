Good tools give the model enough structure to choose and call them correctly. This domain asks you to reason about tool descriptions, input schemas, permission boundaries, and the shape of successful and failed responses. MCP adds a standard way to expose capabilities, but the same design decisions still matter.

## What to practice

- Choose narrow tool inputs and outputs for a specific job.
- Distinguish validation failures from transient service failures.
- Decide when an MCP server is useful and how its capabilities should be scoped.
