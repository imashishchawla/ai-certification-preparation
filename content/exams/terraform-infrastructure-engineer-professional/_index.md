## Official objective map

HashiCorp publishes seven objectives and their sub-objectives. It does not publish domain weights, a passing score, or a fixed question count in the official material reviewed, so this track does not assign estimates to those values.

1. **Scalable Terraform Configuration Design** — business requirements, secure and predictable configuration, expressions, dynamic resources, advanced configuration, providers, and Terraform MCP for AI coding agents.
2. **Terraform State and Backend Operations** — remote backends, drift, dependency chains, upgrades, and state inspection.
3. **Infrastructure Lifecycle and Operations** — project scale, plan/apply, imports, lifecycle management, environments, troubleshooting, data flow, and provider/module versions.
4. **CI/CD and Automation Workflows** — pipeline behavior, deployment strategies, dynamic credentials, and variable-file overrides.
5. **Terraform Security and Governance** — secrets and rotation, pipeline identity, policy and compliance, and risky changes.
6. **Advanced Module Usage and Registry Practices** — module refactoring and contracts, registry use, and module testing.
7. **HCP Terraform / Enterprise Operations** — operations, cost and usage, multi-environment configuration, workspace upgrades, and Policy as Code.

The machine-readable objective catalog in the repository records the official objective IDs for future coverage mapping.
